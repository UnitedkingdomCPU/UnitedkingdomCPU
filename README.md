## 📂 Мои проекты

### 🏢 [Корпоративная сеть TechCorp — Cisco Packet Tracer](https://github.com/UnitedkingdomCPU/Cisco-Packet-Tracer)
**Масштабный проект корпоративной инфраструктуры на 200+ пользователей**

<div align="center">
  <img src="https://media.tenor.com/J0gFU30Yg1AAAAAi/cat-typing.gif" width="150" alt="Typing cat">
</div>

**Что реализовано:**
- ✅ Трехуровневая иерархическая сеть (Core → Distribution → Access)
- ✅ 15+ VLAN с полной сегментацией трафика
- ✅ Active Directory с 200+ пользователями
- ✅ IP-телефония (CUCM) с QoS
- ✅ Веб-сервер, почта, 1С:Предприятие
- ✅ IoT-инфраструктура (датчики, камеры, умный офис)
- ✅ Беспроводная сеть через WLC
- ✅ Сетевая безопасность (ACL, Port Security, DHCP Snooping)

**Технологии:** `Cisco` `VLAN` `OSPF` `NAT` `HSRP` `EtherChannel` `VoIP` `IoT`
